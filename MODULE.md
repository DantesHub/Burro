# Burro architecture

## Ownership

- `Sources/Burro/App`: app/window/menu bar scenes, macOS activation, and explicit runtime Dock icon from the declared bundle resource to avoid stale Launch Services artwork.
- `Sources/Burro/Views`: navigation, overview, evidence inspector, settings.
- `Sources/Burro/Stores/AppStore.swift`: main-actor state, independent Git (30 seconds) / local-agent (3 seconds) / remote-agent (10 seconds) refresh loops, local preferences, and native open/reveal actions. Remote results are accepted only when their original host configuration still matches; merged activity never enters the local cleanup scanner.
- `Sources/Burro/Notch/NotchController.swift`: one nonactivating `NSPanel`, screen/Space placement, passive local/global pointer movement observers, common-run-loop-mode hover deadlines, pin/collapse lifecycle, provider chat navigation on row click, and explicit dashboard routing. Hover uses global screen coordinates, not SwiftUI/native view enter/exit events. Native menu tracking temporarily extends hover ownership so options menus remain usable outside the panel bounds. Event tokens and pending timers are removed on shutdown. Local unified logs record only hover/expansion booleans and event source, never session metadata or coordinates.
- `Sources/Burro/Notch/NotchSurfaceView.swift`: a black `CAShapeLayer`, matching content mask, and two fixed-size SwiftUI hosts. Compositor keyframes own outline, opacity, and a small content translation. The controller grows the native canvas before opening and shrinks it after completion; generation checks ignore cancelled completions. Hit testing/accessibility explicitly select the active host because layer opacity alone does not hide an NSView from input.
- `Sources/Burro/Notch/NotchView.swift`: compact running/attention indicators, slim attention queue, explicit worker disclosure, optional idle filtering, stable list reconciliation, and machine-scoped monitoring detail navigation. It never owns hover timing or animation. The expanded header retains butter; the compact view has no logo or idle fallback.
- `Sources/Burro/Notch/NotchAgentRow.swift`: fixed-height chat navigation targets with live status and disabled unavailable rows; a parent's worker attention is labeled explicitly.
- `Sources/Burro/Notch/NotchHealthView.swift`: scoped connection/coverage messages and retry within the panel, avoiding a hover-breaking popover.
- `Sources/BurroCore/NotchFeed.swift`: explicit same-host/provider parent resolution, nested/cyclic/missing-parent fallback, worker grouping, deterministic attention ordering, and stable list membership with live status reconciliation. Raw session inventory and cleanup decisions remain untouched.
- `Sources/Burro/Views/RemoteHostsSection.swift`: explicit SSH host editor, enable/edit/remove settings, and connection prerequisites.
- `Sources/Burro/Views/RemoteSessionsView.swift`: host-grouped session list and remote-only inspector; remote row selection never resolves against a local worktree.
- `Sources/BurroCore/RemoteHost.swift`: validated host configurations, namespaced session provenance, connection state, stale sample projection, and safe last-seen retention.
- `Sources/BurroCore/RemoteAgentMonitor.swift`: fixed OpenSSH argument construction, bounded command execution, versioned response decoding, and per-host session identity. Optional Claude desktop/bridge IDs remain compatible with protocol v1 and are validated again before navigation.
- `Sources/BurroCore/Resources/remote_probe.py`: Python 3 read-only probe sent over SSH stdin; macOS/Linux process identity, Codex locks/events/completion envelopes, and Claude metadata/completed-turn evidence. It sends bounded completed history alongside live sessions; the viewer filters unread results locally, and reserves inspection time for Claude. Maintain provider semantics alongside `AgentParsing`; `script/test_remote_probe.py` covers the Python side. The SwiftPM resource bundle must be copied into the app by the build script.
- `Sources/BurroCore/NotchHoverState.swift`: deterministic immediate entry, 120 ms exit grace, reentry cancellation, explicit pinning, and manual-dismissal suppression until exit.
- `Sources/BurroCore/NotchMotion.swift`: analytic critically damped position/velocity, reversal continuity, 120 Hz compositor keyframe sampling, and display-coordinate hover regions with approach/exit tolerance.
- `Sources/BurroCore/AgentChatLink.swift`: allowlisted navigation-only URLs from validated provider IDs. Codex strips its Burro remote namespace and resolves the thread through the provider catalog. Claude prefers this Mac's desktop ID, otherwise its bridge ID; remote desktop IDs and bare CLI UUIDs cannot launch a local session. Missing URLs/Launch Services failures fall back to the Burro inspector; right-click always exposes Show in Burro.
- `Sources/BurroCore/AgentActivity.swift`: fast read-only provider sampling and deterministic attention-first ordering, including unread completions. `AgentSession.isDone` is a presentation projection and does not change lifecycle/cleanup state.
- `Sources/BurroCore/ProviderReadState.swift`: provider-owned unread lists, Codex account selection from non-secret creator metadata, Claude completed-turn metadata, and local/remote projection. Read markers are sampled on the utility task, then reapplied to remote results at each local refresh. Never writes or acknowledges provider state.
- `Sources/BurroCore/ChromiumReadState.swift`: bounded read-only access to the allowlisted Claude preference. CURRENT/MANIFEST selects live tables; indexed blocks, Snappy, CRC32C, WAL sequence numbers, and tombstones avoid stale unread markers. File rotation/corruption fails closed. No LevelDB library, locks, provider hooks, or credential access.
- `Sources/BurroCore/NotchGeometry.swift`: pure camera-safe placement for notched, external, offset, and small displays.
- `Sources/BurroCore/PreferencesMigration.swift`: one-time allowlisted preference import from Grove without overwriting Burro settings.
- `Sources/Burro/Support/Presentation.swift`: semantic colors, spacing, filters, status labels. `WindowProbe.swift` registers the actual dashboard window weakly with the notch controller so explicit inspection and unavailable-link fallbacks reuse it.
- `Sources/BurroCore/Scanner.swift`: repository discovery, bounded concurrent inspection, longest-path ownership joins.
- `Sources/BurroCore/GitReader.swift`: porcelain parsing and read-only Git evidence.
- `Sources/BurroCore/AgentReader.swift`: local Codex and Claude adapters and event-state interpretation. Codex source metadata identifies internal sub-agent runs; retain their lifecycle/safety evidence but exclude them from unread completion notifications. Prefer Codex `name` over its original-prompt `title`. Extract validated thread-spawn parent IDs and namespace them alongside remote session IDs. Keep classification, parent parsing, and title precedence aligned with the remote Python probe.
- `Sources/BurroCore/ProcessReader.swift` and `Sources/CSystem`: same-user kernel process identity, cwd, lock inspection, system SQLite bridge.
- `Sources/BurroCore/SafetyPolicy.swift`: pure conservative cleanup policy.
- `Sources/BurroCore/CommandRunner.swift`: argument-array subprocess execution, private temporary output files, timeout enforcement, Git environment isolation.
- `Sources/BurroInspect`: JSON CLI using the same scanner as the app.
- `Tests/BurroCoreTests`: safety matrix, parser/provider states, nested path ownership, real temporary Git worktree integration, subprocess timeout, active-feed filtering, display geometry, the real AppKit frame constraint, actual presentation-layer intermediate frames sampled with a display link, stable native frames during collapse, motion position/velocity continuity, interruption/completion races, Reduce Motion, approach margins/top-edge inclusion/exit hysteresis/reentry/pinning, compact bounds, provider chat-link identity and injection boundaries, and rename preference migration.
- `script/build_and_run.sh`: debug/release app bundling, local icon generation, ad-hoc signing, and launch/debug modes. `VERSION` and `BUILD_NUMBER` own bundle version metadata. `script/generate_icon.swift` renders the system butter emoji locally; generated artwork is ignored. `script/verify_bundle.swift` validates packaged resources through Foundation across SwiftPM bundle layouts. `.github/workflows/ci.yml` runs headless Swift checks, release bundling, and macOS/Linux probe fixtures.

## Invariants

1. Never mutate monitored repositories or provider configuration. Network access is limited to SSH hosts explicitly configured by the user. No Git remote fetch, cleanup action, provider configuration change, or installed hooks.
2. Unknown checks and adapter errors cannot yield a safe candidate. Open idle agents are in use, not disposable.
3. Keep local-ref evidence distinct from verified live remote state. Safe candidate remains advisory.
4. Git commands use fixed executable paths and argument arrays. A repo path/ref is never interpolated into shell source. Read Git status with optional locks disabled and fsmonitor disabled.
5. Never read provider auth files or retain prompt/tool bodies. SSH uses existing OpenSSH authentication without importing it into Burro. Transcript inspection parses event envelopes and discards content.
6. Manual protection adds a blocker; it cannot override dirty data or other evidence.
7. The frontend never executes shell commands supplied by branch names, filenames, or agent titles.
8. Notch/menu-bar activity is sampled independently of the full Git/worktree snapshot. The fast feed does not loosen cleanup advice between full scans. A session selection preserves the intended worktree when switching dashboard filters.
9. The notch does not take main-window status or activate the dashboard on hover. It uses no global keyboard monitor or provider hooks. Preference changes and screen/Space changes reconfigure the single app-owned panel; shutdown removes observers and the local Escape handler. `AgentNotchPanel.constrainFrameRect` deliberately preserves the frame computed by `NotchGeometry`; AppKit otherwise displaces even a borderless panel below the menu bar. Only the pin button makes expansion persistent; clicks and keyboard opening remain transient after the first pointer visit. Manual collapse does not order the window out and back in. Passive local/global mouse-movement observers remain active across application focus; no per-frame polling, keyboard monitoring, or provider hooks are involved. An 8-point approach margin opens immediately; a 10-point expanded margin and 120 ms exit deadline prevent edge flicker. The expanded interaction footprint remains available during closing for immediate reentry. Core Animation owns outline/fades without per-frame SwiftUI layout or NSWindow resize, preserving both position and velocity when retargeted. Reduce Motion skips interpolation. The native window releases its temporary expanded input footprint after completion. The hosting views disable automatic safe-area and content-size adjustments because geometry already reserves the camera. Safe top insets still reserve a conservative camera gap if auxiliary screen rectangles are unavailable.
10. Remote session IDs include their Burro host UUID; remote paths remain literal, and local worktree resolution refuses remote origins. Offline/expired samples become unknown and cannot count as working. No cloud relay or provider desktop pairing is reused. SSH uses strict host-key checks and batch authentication; the remote command is constant, and metadata never becomes a shell command.
11. Chat navigation only opens fixed provider URL schemes and routes derived from validated IDs. No prompt, folder, credential, CLI import/resume, or remote command is included. Claude remote bridge IDs may navigate the local app; another machine's local desktop ID must never do so.
12. Freeze list membership/order during expanded pointer or keyboard interaction. Keep metadata live, disable missing targets, and expose explicit refresh for pending membership changes. Unfreeze on pointer/key-focus exit; explicit filter/disclosure actions may change layout. Do not acknowledge provider unread markers or infer worker parents from paths/titles.
13. Restore original preferences once, copying only explicit repositories, protections, discovery, and comparison branches. Preserve any already-configured Burro values.

## Known boundaries

This is an unsandboxed, locally ad-hoc-signed desktop utility: system process inspection and provider files require normal user read access. App Store sandbox packaging is not implemented. The app store owns the refresh task, so monitoring continues when the main window closes; individual subprocesses have deadlines. Monitoring cannot eliminate time-of-check/time-of-use races, observe unconfigured hosts or cloud tasks, or guarantee all processes are visible. Discovery is bounded rather than a full filesystem crawl; missing directories and private provider schema changes are reported where observable.

Unread integration boundaries and account-switch behavior are documented in [usage guide](docs/usage.md#done-and-unread-status). Keep the Swift and Python completion parsers consistent; completion evidence alone never implies unread.
